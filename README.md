# Bank Extension - Simple Bank Management System

## Introduction  
Bank Extension is an improved version of the original **Bank Management System**, adding a few extra features while keeping it simple and easy to use.

## Features  
This system allows users to manage bank accounts with the following features:  

✅ Create new client accounts with basic details.  
✅ View and list all existing client records.  
✅ Update client information such as name and balance.  
✅ Delete client accounts if needed.  
✅ Store data in a text file (`ClientsRecord.txt`).  

## Improvements from the Original Project  
The **Bank Extension** builds on the first version with some useful additions:  

🚀 **Better User Interface** – Improved text formatting for easier reading.  
🔐 **Basic Data Validation** – Helps prevent incorrect inputs.  
📊 **Deposit & Withdraw Menu** – Added a transactions menu with options to deposit, withdraw, and check total balance.  

## How to Use  
1. Open **Visual Studio**.  
2. Load the project file.  
3. Click **Build** to compile the program.  
4. Click **Run** to start the application.  

## Important Note  
📂 **The `ClientsRecord.txt` file must be in the same folder as the project** for the system to work correctly. This file is used to store the client account data.
